# Многоцелевая модель для NER + Event Classification

Объединённая (multi-task) модель, решающая **NER (BIO, token-level)** и **CLS (document-level multihot событий/отношений)** на датасете NEREL.

---

## Описание

Проект реализует единую модель, которая одновременно выполняет две задачи:
- **NER (Named Entity Recognition)** — извлечение именованных сущностей на уровне токенов в формате BIO
- **Event Classification** — многозначная классификация событий/отношений на уровне документа (multihot)

Модель использует uncertainty-weighting для балансировки loss между задачами и поддерживает квантизацию до INT8 с минимальной потерей качества.

### Ключевые особенности:
- Multi-task архитектура на основе общего энкодера
- Uncertainty-weighting для автоматической балансировки loss
- Поддержка квантизации INT8 (уменьшение размера в 1.5x, ускорение инференса ~20%)
- Token-level F1 micro > 85%, cls-level F1 micro > 80%
- Детальный анализ ошибок и сравнение FP32 vs INT8

## Архитектура модели

```
Input Tokens → BERT Encoder → [CLS] token → CLS Head → Event Labels (multihot)
                            └→ Token Embeddings → NER Head → BIO Tags
```

**Loss:**
```
L_total = w_ner * L_ner + w_cls * L_cls
```
Веса `w_ner` и `w_cls` вычисляются автоматически через uncertainty-weighting (Kendall et al.).

## Выводы

Многоцелевая модель эффективно решает задачи NER и CLS одновременно, не требуя отдельных моделей для каждой задачи.

Квантизация до INT8 уменьшает размер модели в полтора раза и ускоряет инференс примерно на 20% с минимальной потерей качества.

Анализ ошибок показывает, что основные трудности связаны с редкими классами и сложными контекстами — например, модель ошибочно классифицирует рядовые действия как события. Также модель путается на вложенных сущностях. Для улучшения можно добавить дополнительные данные или использовать CRF-слой поверх NER head.
